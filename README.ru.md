# MyScreen — витрина проектов

Личная страница-портфолио: тёмное киберпанк-оформление в деловой подаче,
карточки проектов и панель «знакомства» с каждым. Статический сайт, без
сборки и сервера.

## Файлы

    index.html                единственная страница, точка входа
    css/style.css             оформление: тёмная база, циановый акцент, сетка
    css/fonts.css             подключение локальных шрифтов
    js/content.js             весь текст на двух языках: интерфейс + проекты
    js/main.js                карточки, фильтры, окно знакомства, переключение языка
    fonts/                    Exo 2 (заголовки) и Inter (текст), латиница + кириллица
    img/og.png                превью 1200×630 для соцсетей и мессенджеров
    img/favicon.svg           иконка вкладки
    img/apple-touch-icon.png  иконка для экрана «Домой» на iOS
    img/journeyman-*.jpg      снимки Journeyman: холст пространства и объект
    img/journeyman-desktop.png снимок настольной версии
    img/brightside-*.jpg      снимки лендинга Brightside
    img/roastery-*.jpg        снимки каталога Roastery
    tools/og-template.html    шаблон, из которого снимается og.png
    robots.txt                разрешение обхода + указатель на карту сайта
    sitemap.xml               карта сайта для Google и Яндекса

`index.html`, `robots.txt` и `sitemap.xml` обязаны лежать в корне: первый —
точка входа сайта, остальные два поисковики ищут только там.

Шрифты лежат в репозитории: сайт не обращается к Google Fonts и не ломается
без интернета. Заголовочный шрифт выбран с кириллицей — у многих «техно»
шрифтов её нет, и русский текст падает на системный.

## Адрес сайта

Адрес прописан в трёх файлах: `<link rel="canonical">` и `og:`-теги в
`index.html` (в том числе `og:image` — путь `img/og.png`), `sitemap.xml`,
`robots.txt`. Сейчас везде стоит
`https://kennys44.github.io/MyScreen/`. При переезде на свой домен поменяйте
эти строки — иначе превью в соцсетях будет тянуть картинку со старого адреса.

## Два языка

По умолчанию страница на английском, переключается на русский кнопкой EN/RU в
шапке. Перезагрузки нет: переключатель на месте меняет видимый текст, `lang`
страницы, заголовок и теги превью для соцсетей.

Какой язык получит посетитель, по убыванию приоритета:

1. `?lang=en` или `?lang=ru` в адресе — явная ссылка всегда главнее, поэтому
   ссылку можно переслать на том языке, который она обещает;
2. выбор, запомненный с прошлого визита (`localStorage`);
3. язык браузера — русский для `ru-*`, английский для всего остального.

При переключении `?lang=` дописывается в адресную строку, так что показанное на
экране можно скопировать и отправить как есть.

Одно следствие, о котором стоит знать: текст подменяется через JavaScript,
поэтому робот, который не исполняет скрипты, видит английскую версию. Это и
задумано как основная; `<link rel="alternate" hreflang>` в `<head>` указывает на
обе.

## Как добавить проект

Весь текст лежит в `js/content.js` — в `main.js` осталась только логика. Каждый
проект описан одним объектом массива `PROJECTS`; карточка, фильтр и окно
соберутся сами:

    {
      id: 'slug',              // уникальный ключ
      title: 'Название',       // не переводится
      kind: 'tool',            // ключ, а не подпись: 'tool' | 'site'
      status: 'live',          // live | wip | idea — цвет метки
      year: '2026',
      tags: ['HTML/CSS/JS'],
      repo: 'https://github.com/KennyS44/...',
      demo: 'https://…',       // необязательно
      shots: [
        { src: 'img/x.jpg', w: 1920, h: 1200,
          alt: { en: 'English alt text', ru: 'Русский alt' } },
      ],
      en: {
        tagline: 'One line of substance',
        summary: 'Paragraph for the card',
        about: 'Paragraph for the project panel',
        features: ['Bullet for the "What is inside" list'],
        stack: 'What it is built with',
      },
      ru: { …те же пять полей… },
    }

`kind` намеренно ключ, а не видимое слово: подпись берётся из `UI['kind.tool']`,
поэтому переключение языка не может сломать текущий фильтр. Строки интерфейса
лежат в объекте `UI` в начале того же файла — один и тот же набор ключей должен
быть и под `en`, и под `ru`.

Число в блоке «Проектов» считается автоматически (слоты со `status: 'idea'`
не учитываются).

## Проверено

Chrome (Playwright), 1280×900 и 390×844, 31 проверка: карточки открываются,
фильтры переключают список, окно закрывается по Esc, фону и крестику,
горизонтальной прокрутки на телефоне нет.

Отдельно про переключение языка: меняются `lang` страницы, заголовок, описание и
`og:locale`; выбранный фильтр переживает переключение и оставляет те же карточки;
открытое окно проекта перерисовывается на месте, а не закрывается; просмотр
изображения закрывается, потому что его подпись осталась от старого языка; выбор
переживает перезагрузку; `?lang=` перебивает запомненный выбор, а неизвестное
значение откатывается к запасному; браузер с `ru-RU` открывает русскую версию,
с `en-GB` — английскую. Ошибок в консоли нет, оба шрифта грузятся локально.
